Claude 101 第一课：What is Claude?

发表于2026-08-14|更新于2026-08-14|AI学习笔记
|字数总计:2.8k|阅读时长:9分钟|阅读量:

⏱️ 预计用时：15 分钟 ｜ 📚 原文出处：Anthropic 官方课程 Claude 101 第一课（本文为中文整理版）

学习目标

完成本课后，你将能够：

  • 解释 Claude 是什么，以及指导其设计的核心原则；
  • 描述 Claude 的核心能力，以及它与简单聊天机器人的区别；
  • 说出访问 Claude 的不同方式（网页、桌面与移动端）。

课程路线图

  • 认识 Claude（Meet Claude）：Claude 是什么？怎么与它对话？怎么拿到好结果？
  • 组织你的工作（Organizing your work）：Projects、Artifacts 和 Skills 如何给 Claude 提供结构化与可复用的知识？
  • 扩展 Claude 的能力（Expanding Claude's reach）：Connectors、企业搜索和 Research 如何把你的工具与互联网带进对话？
  • 综合运用（Putting it all together）：Claude 在各个岗位上的实战是什么样子？还能在哪些地方使用它？
  • 总结与证书（Conclusion & certificate）：接下来学什么？如何拿到结业证书？

Claude 是什么？

Claude 不只是一个聊天机器人——它是一个被设计成你的思考伙伴（thinking partner）的 AI 助手。本课会带你了解 Claude 与其他 AI 工具的不同之处，以及它如何协助各种类型的工作任务。

核心要点

  • Claude 被构建为有用、无害、诚实（helpful, harmless, honest）：从宏观上看，Claude 受一组原则的指导——避免产生有毒或歧视性的输出、拒绝协助非法或不道德的行为，并整体表现为一个有用、诚实、无害的 AI 系统。这套方法叫做 Constitutional AI（宪法式 AI），意味着 Claude 被训练为与人类价值观对齐、透明地运作。
  • Claude 不只是聊天机器人：Claude 能以高可靠性、高可预测性完成多种对话与文本处理任务——摘要、检索、创意与协作写作、问答、编程等等。把 Claude 当作一个能帮你攻克复杂问题、陪你梳理棘手局面的思考伙伴，而不只是回答简单问题的工具。
  • Claude 被设计为可引导、可协作（steerable）：Claude 可以按你的要求调整个性、语气与行为方式。用户反馈显示 Claude 更不容易产生有害输出、更容易对话、也更听得懂指挥——你可以用更少的力气得到想要的结果。
  • 随时随地都能使用：Claude 应用对所有订阅类型开放——Free、Pro、Max、Team 与 Enterprise。登录后，你的对话、项目、记忆与偏好会在所有设备间同步。无论在工位还是在路上，都可以通过网页、桌面与移动 App 使用 Claude。

理解 Claude 的能力

Claude 能做的远不止一问一答——它是一种助手式的伙伴关系，既能自动化你的工作，也能增强你的工作。

练习：哪些请求需要「思考伙伴」？

课程里有一个把六个请求分成两栏的练习。分界线从来不在话题本身——评论、发票、汇率都可以敲进搜索框。真正区分两栏的是：答案里需不需要「你」——你的草稿、你上一版的方案、你对客户的判断。搜索框接收的是一个问题，Claude 接收的是一个处境。

🔍 搜索框就能解决的：

  • “今天美元兑欧元的汇率是多少？”
  • “采购订单（PO）和发票（Invoice）有什么区别？”
  • “3 月 3 日到 3 月 24 日之间有多少个工作日？”

🤝 需要 Claude——以及你——的：

  • “把我下面这段进度说明改写一下，让延期读起来像一个决策，而不是一句道歉。”
  • “季度业务复盘（QBR）演示的最佳结构”——同样的需求，敲成关键词是查询，交代清楚处境就是协作。
  • “我把客户的投诉记录贴在下面了。回复之前，先帮我弄清楚他们真正想要的是什么。”

Claude 特别擅长的事

  • 写作与内容创作：与你协作完成社交媒体帖子、专业邮件和复杂报告。由于 Claude 被训练为可接受个性与语气方面的指示，你们可以就结构与清晰度反复迭代，直到你的声音清楚地呈现出来。
  • 研究与分析：帮你探索研究角度、汇总发现、分析数据并提炼有意义的洞见。你可以上传文档让 Claude 帮你理解复杂信息——这得益于 Claude 的超大上下文窗口：可容纳 20 万+ tokens（约 500 页以上文本），Pro、Max、Team 与 Enterprise 计划在受支持的模型上最高可达 100 万 tokens，让 Claude 能在一次对话里通盘考虑大量材料。
  • 编程协助：编程是 Claude 最强的能力之一。它在真实世界编程任务上的出色表现，意味着它能帮你编写、调试和解释多种编程语言的代码。
  • 解决问题与推理：Claude 能处理复杂的认知任务、数学问题、战略分析与研究。它既可以近乎即时地回答，也可以先花时间推理再作答——这个能力叫 Thinking（思考）。当问题需要仔细分析时，Claude 会一步步推演后再给出答案。
  • 学习新事物：无论你在学一项新技能、探索陌生领域，还是攻克复杂难题，Claude 都能适应你的学习风格与节奏。Learning mode（学习模式）是一种新的体验：它引导你的推理过程而非直接给答案，帮助你锻炼批判性思维。

想按自己的岗位找灵感，可以浏览 claude.com 上的用例库（use-case gallery）；想更深入了解 AI 能做什么、不能做什么，可参阅官方的 AI Capabilities 课程。

访问 Claude 的方式

Claude 是「智能」本身——你在整门课程中学习协作的那个 AI 助手。同一个智能可以通过多种界面使用，各自适合不同类型的任务：

  • Claude.ai（及配套的移动与桌面 App）：大多数人使用 Claude 的主要方式。你可以提问、头脑风暴、创建与编辑文档等。适合对话、写作协助、研究、分析与文件创作——也是本课程的重点。
  • Claude Code：面向开发者的智能体编程工具，也可用于桌面上的各类文件操作。Claude Code 可以直接编辑文件、运行命令、创建提交。
  • @Claude（Slack 中的 Claude）：把 Claude 直接带进 Slack。你可以在任意频道或会话的 AI 助手入口与 Claude 聊天，或在讨论串里 @Claude。连接 Slack 后，Claude 能搜索工作区的频道、私信与共享文件，为回答与研究找到所需上下文。
  • Claude Design：把想法变成可用界面的专属空间。描述你想要的东西——或从草图、截图出发——Claude 会构建一个可交互的原型，供你打磨并交付给团队。
  • Claude for Microsoft 365：以侧边栏形式进入 Excel、PowerPoint、Word 与 Outlook，让你在已打开的文档里直接分析、起草与编辑，并把上下文从一个应用带到下一个。

本课程主要聚焦 Claude.ai；如需了解开发工作流中的用法，可查看官方的 Claude Code in Action 课程。

课后思考

你当前工作中的哪些任务，可能受益于把 Claude 当作思考伙伴？看看你的日程表（或者更好——让 Claude 帮你看），找出几个你想让 Claude 支持的任务。
